# Rapha Development Profitability Model (የራፋ የግንባታ ፕሮጀክት ትርፋማነት ሞዴል)

An Excel template that tells a home builder what a house will cost and how to finance it (Mode 0), or tells a developer, investor or lender whether a building project in Ethiopia makes money (Modes 1–3: sell, rent, mixed). It includes 10-year IFRS statements, a loan amortization schedule, returns, live sensitivity and break-even analysis, and 23 integrity checks.

- `output/Rapha_Development_Profitability_Model_v1.xlsx` — the template with two sample projects
- `output/Rapha_Model_Blank.xlsx` — a blank copy
- `output/Rapha_Model_Tutorial_AM.pdf` — the Amharic user guide
- `output/BUILD_NOTE.md` — counts, verification results, assumptions and the tax rates to confirm
- `build/` — the generator (openpyxl) and the QA harness; `tutorial/` — the guide generator (HTML → Chromium PDF)

Planning tool only. It is not investment, tax or legal advice.
